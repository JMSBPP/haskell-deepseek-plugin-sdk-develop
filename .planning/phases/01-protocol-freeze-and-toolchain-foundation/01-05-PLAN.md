The failures worth anticipating, and what each means:

- **`generated .cabal is current` fails** — `package.yaml` was edited without
  committing the regenerated `.cabal`. Run `stack build` locally and commit the
  `.cabal`.
- **`conformance` fails with `OK (unexpected: …)`** — a scenario passes while its
  `EXPECTED.md` still exists. That is the design working; delete the file or fix
  the stub.
- **`red state is visible` fails** — `scripts/check-red-visible.sh` is not
  executable in the index. `git update-index --chmod=+x scripts/check-red-visible.sh`.
- **`build` fails only in CI** — `--pedantic` is `-Werror`, and GHC 9.10.3 on the
  runner is the same version as local, so this is a genuine warning that a local
  incremental build did not recompile. Run `stack clean && stack build --pedantic
  --test --no-run-tests` locally.
- **The `hlint` or `fourmolu` step shows a red X but the job is green** — expected.
  Both carry `continue-on-error: true` until Phase 7.

Record in the summary, for each remote: the run URL, the head SHA, the
conclusion, and whether the advisory `hlint` and `fourmolu` steps passed or
reported findings. The advisory result matters because Phase 7 makes them
blocking and needs to know today's baseline.
